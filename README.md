# Event Management System V.2

ASP.NET Core MVC rebuild of a private university event management graduation project.

## Original Project Context

The original version was built by a team of two as a graduation project.

My responsibilities included:

- Front-end development
- Quality assurance testing
- Documentation
- ERD preparation
- Table relationship documentation

## Rebuild Goal

This repository contains an independent rebuild of the system with cleaner architecture,
role-based access control, Entity Framework Core, SQL Server, and testable business logic.

## Core Features

- Admin event management
- Student event browsing
- Event registration
- Waiting list
- Booking cancellation
- Automatic waiting-list promotion
- Admin dashboard
- Registration reports

## Tech Stack

- ASP.NET Core MVC
- .NET 8
- Entity Framework Core
- SQL Server LocalDB
- ASP.NET Core Identity
- Bootstrap 5
- Razor Views
- xUnit
